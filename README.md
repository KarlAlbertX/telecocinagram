# Telecocinagram 🍳💻

> Una plataforma social culinaria modular, local y autohospedada optimizada para entornos Termux.

## 🏛️ Arquitectura Modular (v1.2.0-alpha)
Telecocinagram está construido con un enfoque modular desacoplado en Node.js y Express:
- **`/src/models/`**: Gestión de entidades y billetera (`wallet.js`).
- **`/src/routes/`**: Puentes financieros e integraciones bancarias (`finance.js`).
- **`/src/security/`**: Políticas de orden y control holográfico (`petrona.js`).

## 👥 Entidades del Sistema
- **chef_master**: Usuario principal y operador de los fogones.
- **Petrona**: Inteligencia de seguridad y guardiana del Decreto del Fregadero Vacío.
- **IABank**: Entidad de micro-financiamiento y liquidez.
- **Binance**: Puente de conversión de activos (`cocinaCoin` a `USD` con tasa 1.25).
- **Developed Lab**: Entidad oficial de desarrollo y autoría.
